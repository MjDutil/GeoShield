# Sistema de Monitoramento Climático e Geoespacial

## Informações do Projeto

Este projeto é um **sistema de monitoramento climático e geoespacial**, desenvolvido como parte de um **projeto prático universitário**. O objetivo do sistema é gerar **mapas de risco em tempo real**, fornecendo informações precisas sobre áreas vulneráveis a **eventos climáticos extremos**, como tempestades, inundações e deslizamentos de terra. Através da visualização de dados geoespaciais, o sistema busca indicar **locais seguros** para a população em situações de calamidade, ajudando a **reduzir os impactos desses eventos** e contribuir para a **preservação da vida humana e do meio ambiente**.

A ideia principal é focar principalmente no **frontend**, utilizando tecnologias modernas para criar uma interface interativa e de fácil uso. A plataforma permite a visualização de **mapas interativos**, onde as áreas de risco são destacadas, oferecendo também **informações detalhadas sobre os eventos climáticos** e rotas de evacuação sugeridas.

## Como editar este código?

Este projeto pode ser editado de várias maneiras:

### Usando sua IDE preferida

Se você deseja trabalhar localmente em sua própria IDE, basta clonar este repositório e fazer as alterações que preferir. As alterações feitas localmente podem ser enviadas para o repositório através de comandos Git.

A única exigência é ter o **Node.js** e o **npm** instalados. Você pode [instalar o Node.js com nvm](https://github.com/nvm-sh/nvm#installing-and-updating).

### Passos para configurar localmente:

```sh
# Passo 1: Clone o repositório usando a URL do Git do projeto.
git clone <YOUR_GIT_URL>

# Passo 2: Navegue até o diretório do projeto.
cd <YOUR_PROJECT_NAME>

# Passo 3: Instale as dependências necessárias.
npm i

# Passo 4: Inicie o servidor de desenvolvimento com recarregamento automático e visualização instantânea.
npm run dev
```

### Editando um arquivo diretamente no GitHub

* Navegue até o arquivo desejado.
* Clique no ícone de "Editar" (lápis) no canto superior direito da visualização do arquivo.
* Faça as alterações e envie as alterações.

## Tecnologias usadas neste projeto

Este projeto foi construído utilizando as seguintes tecnologias:

* **Vite** para build e desenvolvimento rápido.
* **TypeScript** para garantir um código mais robusto e com tipagem forte.
* **React** para construção de interfaces dinâmicas e interativas.
* **Tailwind CSS** para estilização rápida e responsiva.

## Como implantar este projeto?

Se você deseja implantar este projeto localmente ou em um servidor, pode configurar seu ambiente com as ferramentas mencionadas acima e iniciar o servidor com o comando `npm run dev`.

Este sistema oferece uma interface acessível para monitoramento e visualização de dados climáticos, ideal para apoiar decisões rápidas e informadas durante emergências climáticas.
